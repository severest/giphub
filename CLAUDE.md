# Giphub - Project Context for Claude

## Project Overview

Giphub is a browser extension (Chrome/Firefox) that allows users to insert GIFs from Giphy into their GitHub comments. The extension injects a content script into github.com pages to add GIF insertion functionality.

## Tech Stack

- **Frontend**: React 19 with React DOM
- **Build Tool**: Parcel (with @parcel/config-webextension)
- **Linting**: XO (JavaScript), Stylelint (CSS)
- **Package Manager**: npm
- **Target Browsers**: Latest Chrome and Firefox versions
- **Manifest Version**: 3

## Key Files

### Manifest ([source/manifest.json](source/manifest.json))

- **Version**: 2.2.0
- **Permissions**: Host permissions for `https://github.com/*`
- **Content Scripts**: Runs [content.js](source/content.js) on all GitHub pages
- **Background**: Service worker at [background.js](source/background.js)

### Content Script ([source/content.js](source/content.js))

- Injects the GIF button UI into GitHub's pull request review dialog
- Listens for `selectionchange` events to render the button
- Targets the "Finish your review" dialog specifically
- Uses React's `createRoot` to render the [GifButton](source/components/gif-button.js) component

## Development Setup

**Requirements**: Node.js v18+

```bash
npm i              # Install dependencies
npm run build      # Build the extension
```

Then load the `distribution/` folder as an unpacked extension in:

- Chrome: chrome://extensions (enable Developer Mode)
- Firefox: about:debugging > This Firefox > Load Temporary Add-on

## Key Dependencies

- **react** & **react-dom**: UI framework (v19)
- **react-icons**: Icon components
- **webext-base-css**: Base styles for web extensions
- **webext-options-sync**: Options page synchronization

## Extension Behavior

1. Extension runs on all `https://github.com/*` pages
2. Content script monitors for the pull request review dialog
3. When detected, injects a GIF button into the dialog
4. Users can click the button to insert GIFs into their review comments
5. The textarea reference is passed to the GifButton component for insertion
